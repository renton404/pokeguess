# PokéGuess

A Pokémon guessing game built with HTML, CSS, JavaScript, and PokéAPI.<br>

🎮 **Play PokéGuess:**  
https://renton404.github.io/pokeguess/

## ✨ Features

- 🎯 4 randomized Pokémon answers
- ❤️ 5 lives + score system
- 🪙 +100 points for correct answers
- 🔀 Fisher–Yates shuffle for randomization
- 🧬 Dynamic Pokémon types & abilities
- ⚔️ Randomized move clues
- 🖼️ Pokémon sprites fetched from PokéAPI
- 💀 Game Over & restart system
- 📱 Responsive design

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- PokéAPI

## 🧠 What I Practiced

- async/await & API requests
- DOM manipulation
- Event listeners
- Game state management
- Array manipulation & Fisher–Yates
- Error handling
- Responsive CSS
